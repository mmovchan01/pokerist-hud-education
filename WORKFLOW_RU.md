# Сбор снимков во время игры → подпись карт после сессии

Для **Windows 11**, приложение **Texas Poker**, отдельный процесс игры.
Внедрения в игру, перехвата памяти и автоматических игровых действий нет.

## Вариант A — прямо из HUD

1. Откройте Texas Poker и запустите HUD обычной кнопкой панели.
2. В HUD включите **«F8: копить снимки Texas Poker»**.
3. Играйте и нажимайте **F8** в интересных ситуациях. Либо нажмите
   **«Снимок в очередь»** в HUD. Редактор в этот момент не открывается.
4. После сессии закройте HUD и в панели откройте
   **«Редактор накопленных снимков»**.

## Вариант B — только сбор, без HUD и расчётов

1. `start_windows.cmd` → **«Сбор снимков во время игры — F8»**.
2. В поле окна уже стоит **Texas Poker**. Если фактический заголовок другой,
   впишите уникальную часть заголовка вашего приложения.
3. Нажмите **«Включить сбор»**. Дождитесь сообщения о регистрации клавиши.
4. Переключитесь в игру и нажимайте **F8**. Окно сборщика можно свернуть.
   На каждое нажатие записывается один **PNG без JPEG-сжатия** и JSON с зонами.
5. После сессии закройте сборщик и откройте редактор в панели.

Не включайте F8 одновременно в двух экземплярах: Windows разрешит сочетание
только одному. В отдельном сборщике можно выбрать **F9/F10** или пользоваться
кнопкой. При занятой клавише показывается ошибка, кнопка снимка остаётся рабочей.
Быстрые повторные нажатия во время сохранения не накапливают очередь старых
снимков — показывается просьба повторить нажатие после сохранения.

**Калибровка для самого сбора не обязательна.** Без неё сохраняется весь клиент
игры, а зоны из стартового профиля помечаются как предложенные: их нужно
проверить и при необходимости поправить в редакторе. С действующим config
зоны копируются в метаданные **каждого** снимка. Позднейшая перекалибровка
не меняет рамки старых снимков. Если заголовок/соотношение сторон отличается
от калибровки, редактор также предупреждает о предложенных зонах.

## Как подписывать карты

1. Слева — список снимков с прогрессом. Выберите кадр.
2. По умолчанию включено **«Только карты»**: программа перебирает `hero1`,
   `hero2`, `board1`…`board5`, не заставляя разбирать цифры после каждого кадра.
3. Текущая область выделена белой рамкой. Ниже показана увеличенная вырезка.
4. Выберите в списке карту, например **A♥ (Ah)**. Ничего печатать не нужно:
   в списке есть все 52 карты.
5. **«Сохранить → дальше»** или **Enter** сохраняет шаблон и переключает на
   следующую неподписанную область, затем на следующий незавершённый снимок.
6. Если карты нет — тип **empty**; рубашка — **back**. Если карту перекрыла
   анимация или она нечитаема — **«Нечитаемо / пропустить»**, не угадывайте.
7. Неправильную рамку можно перерисовать мышью на полном снимке перед сохранением.
8. Для цифр снимите «Только карты», выберите область, выделите **один символ**
   мышью, сохранив вертикальную высоту строки, нажмите **«Добавить выделение»**,
   выберите тип **glyph** и нужный символ из списка. Для других символов
   повторите добавление. Не подписывайте всю строку `12.5K` как одну цифру.

Прогресс сохраняется при **каждом нажатии «Сохранить» или «Пропустить»**.
Можно закрывать редактор и продолжать позже. Несохранённая рамка не экспортируется.
Повторное открытие готового кадра позволяет исправить метку: старый управляемый
шаблон удаляется, новый помещается в правильную папку. Повторное сохранение
одной области не создаёт дубликатов. Ручные шаблоны из других инструментов
не удаляются. Статус «пропустить» можно позднее заменить правильной подписью.

Есть фильтр **«Только незавершённые снимки»**. Готовые скрываются с учётом режима
«Только карты». Кнопка **«Импорт PNG/JPEG»** позволяет разобрать уже сделанные
снимки; для импортированных файлов зоны всегда считаются предложенными.
Не запускайте два редактора для одного альбома одновременно. При обнаружении
изменения текущей записи другим редактором потребуется обновить список.

## Где находятся файлы

```text
captures/inbox/
    <id>.png           # исходный снимок только игры
    <id>.json          # исходные зоны, подписи и прогресс

templates/
    card/Ah/album_...png
    empty/empty/album_...png
    glyph/dot/album_...png
```

Эти локальные папки исключены из Git. Снимки могут содержать ники, чат и баланс;
проверяйте их перед отправкой кому-либо. Для резервной копии сохраняйте вместе
**captures/inbox** и **templates**, не только PNG. Шаблоны редактора именуются
с префиксом `album_`; исходные снимки не изменяются при разметке.

После массовой подписи перезапустите HUD, чтобы он загрузил новые шаблоны.
Скриншоты сами по себе не обучают распознавание: экспортируются только явно
подтверждённые пользователем метки.

## Захват именно окна, не рабочего стола

Используется Win32 **PrintWindow** для клиентской области Texas Poker.
Рамка ОС, панель задач, рабочий стол, HUD и другие окна не включаются в снимок,
если игра поддерживает этот способ отрисовки. Найдено несколько совпадающих
окон — ошибка, а не случайный выбор. Свёрнутое/закрытое окно — ошибка.
При ошибке **нет автоматического перехода на скриншот рабочего стола**.

**Ограничение Windows/движка игры:** DirectX может вернуть чёрный, устаревший или
неполный кадр. Почти чёрные кадры отклоняются автоматически, но старый кадр
универсально обнаружить нельзя. Первые PNG обязательно откройте и проверьте.
Если кадр чёрный, попробуйте оконный или безрамочный полноэкранный режим.
Если PrintWindow не работает даже так, понадобится другой backend (например,
Windows Graphics Capture); он сейчас не реализован. Не запускайте игру от
администратора без необходимости — разный уровень прав может мешать захвату.

В живом HUD на Windows при заданном заголовке тоже используется нативный
захват окна. Панель передаёт **Texas Poker**; запуск напрямую без заголовка
берёт заголовок из config либо Texas Poker. Для другого заголовка:
`python main.py --run --window-title "Texas Poker"`.
Старый ручной MSS-захват остаётся для калибратора/профилей без заголовка и
других ОС; новый сборщик F8 никогда его не использует.

## Закрепление поверх окон

В HUD появилась явная галочка **«Закрепить HUD поверх всех окон»**. По умолчанию
она включена; её можно выключить и включить обратно. Сборщик и редактор также
имеют переключатель «Поверх всех окон». Это обычный `topmost` Windows, не
внедрение в рендер игры: он работает поверх обычных/безрамочных окон, но не
гарантирует отображение поверх эксклюзивного DirectX fullscreen, UAC/защищённого
рабочего стола или другого topmost-окна. Для HUD предпочтителен безрамочный режим.

## CLI

```bash
python main.py --record --window-title "Texas Poker"
python main.py --label
python main.py --label --album captures/inbox --templates templates
```

Win32-захват и глобальная F8 требуют проверки на вашем Windows 11.
Тесты на headless Linux проверяют хранение, экспорт, исправления, рабочий поток
и вызовы подставного Win32 API, но не доказывают совместимость с рендером игры.
