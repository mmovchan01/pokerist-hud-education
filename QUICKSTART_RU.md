# Настройка поверх открытой игры — без команд после установки

## Самый простой сбор шаблонов во время игры

Для приложения **Texas Poker**: HUD → галочка **«F8: копить снимки»** → играйте
и нажимайте **F8** → после сессии закройте HUD и откройте в панели **«Разобрать и подписать карты»** → выберите карты из списка, Enter для сохранения.
Отдельный сборщик F8 доступен и без HUD, калибровка для самого сохранения PNG
не обязательна. [Полная инструкция](WORKFLOW_RU.md).

## 1. Откройте панель

**Windows:** установите Python 3.10+ с python.org (компонент **Tcl/Tk**, опция
**Add Python to PATH**). В папке проекта дважды нажмите **`start_windows.cmd`**.
В первый раз скрипт создаст `.venv` и скачает зависимости. Не нужны права
администратора и отключение политики PowerShell. При следующих запусках
установка пропускается, пока не изменился `requirements.txt`.

**Linux/macOS:** Python с Tk, затем `sh start_desktop.sh` из папки проекта.
На Debian/Ubuntu дополнительно нужны системные `python3-tk`, `python3-venv`.

Если зависимости повредились: `python bootstrap.py --repair`.
Все данные сохраняются **в папку проекта**, независимо от того, откуда
вы запустили панель. Не размещайте проект в защищённой от записи папке.

## Первые три минуты после установки

1. На вкладке **«Начать работу»** откройте **«Собрать снимки»**.
   Заголовок окна — **Texas Poker**. Включите сбор и нажмите F8 в игре.
   Проверьте кадр в предпросмотре. Калибровка для сохранения не обязательна.
2. Закройте сборщик → **«Разобрать и подписать карты»**. Слева выберите кадр,
   в центре проверьте рамку, справа прочитайте результат сравнения и подтвердите
   правильную карту кнопкой **«Подтвердить и дальше»**. Автопропуск выключен.
3. В **«Базе карт»** проверьте образцы. Для HUD сначала откройте
   **«Настройка стола»** → профиль/зоны → **«Проверить один кадр»**.
   Для знакомства без игры используйте **«Тренироваться без запущенной игры»**.

Это старт маршрута, а не обещание заполнить всю колоду за три минуты.
Подробнее о помощнике и исправлении ошибок: [WORKFLOW_RU.md](WORKFLOW_RU.md).

## Упрощённый вариант для ваших присланных скриншотов

В панели есть на вкладке «Настройка стола» кнопка **«Применить профиль вашего 3D-стола»**. Откройте тот же 3D-стол,
нажмите эту кнопку и переключитесь в игру. На снимке выделите **только всё
изображение Pokerist**, включая его верхнее меню и нижние кнопки, без рамки ОС и панели задач. Зоны карт и чисел расставятся автоматически. Нажмите «Сохранить
config»; для привязки к Windows выделение должно совпадать с клиентской областью окна.

Затем перейдите к проверке кадра (раздел 4). В HUD число оппонентов задайте
вручную. Все карты повторно подписывать не нужно: доступны 13 разных карт
из ваших кадров, но неизвестные карты ещё потребуют шаблонов. Часть чисел и
неактивные кнопки пока не читаются — неизвестное не подменяется нулём.
[Таблица результатов по шести кадрам](profiles/pokerist_3d_1280x719/README.md).

Следующие шаги обычной разметки нужны, если надо исправить отдельную зону
или если используете другой вид стола. **У первой карты героя в готовом
профиле намеренно выделена только видимая часть** — её перекрывает вторая.

## 2. Откройте игру и разметьте стол

1. Откройте приложение **Texas Poker на Windows 11**. Используйте оконный
   или безрамочный режим с постоянным соотношением сторон.
2. В Windows можно вписать в панели **уникальную часть заголовка окна игры**:
   например, **Texas Poker**. Тогда клиентская область выберется автоматически. Если найдено
   несколько окон, задайте более точный заголовок. На Linux/macOS оставьте
   поле пустым — область выбирается вручную.
3. Нажмите **«Настройка стола» → «Исправить зоны вручную»** и сразу переключитесь на игру (Alt+Tab).
   Панель свернётся. Через четыре секунды будет снят экран и откроется редактор.
4. Если не указали заголовок, сначала выделите область игры на снимке.
   Если собираетесь привязать окно Windows позже, выделение должно совпадать
   с **клиентской областью всего окна**, а не только нарисованным столом.
5. Следуйте подсказкам над картинкой. Выделяйте мышью:
   - `hero1`, `hero2` — ваши карты целиком;
   - `board1`…`board5` — пять мест борда, включая пока пустые;
   - `pot`, `stack`, `call` — только числовые строки, без подписей и валюты;
   - `opp1`… — рубашки у всех мест, где могут играть соперники, без аватаров;
   - `oppstack1`… — необязательно, стеки соответствующих соперников.
6. Нужна другая ситуация на столе? Нажмите **«Новый кадр (3 с)»**, переключитесь
   в игру. Окна текущего помощника скроются перед снимком и затем вернутся.
   Уже выделенные зоны останутся. Координаты вручную вводить не нужно.
7. Нажмите **«Сохранить config»**. Повторное открытие редактора загрузит зоны;
   можно исправить отдельную. Предыдущая версия сохраняется в `config.json.bak`.
   Кнопка **«Выбрать область заново»** позволяет сменить стол без удаления файлов.

Не нажимайте игровые кнопки, пока выделяете области: вы работаете на
замороженном скриншоте в отдельном редакторе, а не внутри процесса игры.

## 3. Соберите первые шаблоны

Закройте редактор, чтобы вернуться к панели. Нажмите **«Настройка стола» → «Быстро сохранить одиночный шаблон»**
и переключитесь в игру. В сборщике:

- Выберите `hero1` / `hero2` / `board…` в списке — зона уже выделена.
  Тип **`card`**: подпишите карту (`Ah`, `Kd`, `Tc`), Enter.
  `T` = десятка; `h` = червы, `d` = бубны, `c` = трефы, `s` = пики.
- **«Следующая зона»** переключает выделение без повторной обводки мышью.
- Для пустого места выберите **`empty`**: метка подставится сама. Сохраните
  пустые слоты борда и пустые места соперников; разные фоны требуют образцов.
- Для рубашки соперника выберите **`back`**: метка также подставится сама.
- Для цифр выберите зону банка/стека/колла (тип **`glyph`**), сузьте выделение
  по горизонтали до **одного** символа и подпишите `0`…`9`, `.`, `,`, `K`, `M`, `B`.
  Вертикальную высоту сохраняйте как у всей строки, **даже у точки**.
- Чтобы снять новые карты, не закрывая сборщик, нажмите **«Новый кадр (3 с)»**.

Это обучение на примерах вашего оформления. Без образца ещё не виденной карты
распознавание может остановиться — добавьте образец вместо снижения порога.
Кнопка Check пока **не распознаётся как нулевой колл**; HUD честно ждёт число.
Для первых запусков можно вручную задать число оппонентов кнопками `−` / `+`.

## 4. Проверьте, что компьютер видит правильно

Нажмите **«Настройка стола» → «Проверить один кадр»**, переключитесь в игру. Откроется снимок:

- зелёные рамки — распознано;
- синие — пустое место;
- красные — неизвестно.

Ниже есть таблица всех значений и similarity score. **Сверьте карты и числа
глазами.** Один правильно распознанный кадр ещё не подтверждает стабилизацию.

В `captures/` появятся исходный PNG, PNG с рамками и JSON со значениями.
Если что-то не работает, пришлите эти **три файла** — по ним можно проверить
координаты и распознавание. Они не попадают в Git автоматически. Перед отправкой
проверьте личные данные. Журналы ошибок панели лежат в `logs/`.

## 5. Запустите HUD

Закройте проверку, нажмите **«Начать работу» → «Открыть HUD и тренера»**. Перетащите HUD за верхнюю
полосу в сторону, чтобы он **не перекрывал игру**. Для рекомендаций требуются
два одинаковых валидных кадра; при неизвестных данных рекомендации скрываются.

Для тренировки без Pokerist есть кнопка **«Тренироваться без запущенной игры»** и «Тестовая
раздача» внутри HUD. Скрывайте ответ галочкой и считайте самостоятельно.

## Частые проблемы

- **Чёрный снимок:** в Windows PrintWindow может не получать DirectX-кадр; попробуйте
  оконный/безрамочный режим. Захвата рабочего стола вместо окна здесь нет.
  Подробные ограничения — в WORKFLOW_RU.md.
- **После перемещения всё съехало:** в Windows используйте привязку к
  заголовку. На остальных ОС повторите выбор области. Если изменилась сама
  вёрстка стола или соотношение сторон, исправьте ROI.
- **Неверные цифры:** ROI должен содержать только число; соберите разные
  шрифты банка, стека и кнопки, не забывайте суффиксы и разделители.
- **Не распознаётся пустота:** добавьте `empty` для конкретного фона. Пустота
  проверяется строго, чтобы незнакомая карта не считалась пустым слотом.
- **Ошибка старого config.json:** скопируйте его в безопасное место и переименуйте
  исходник, затем повторите разметку. `config.json.bak` можно восстановить вручную.
- **После установки Python окно не открывается:** сообщение остаётся в консоли.
  Проверьте Tcl/Tk; с журналом `logs/` проще найти проблему.

Инструменты не внедряются в клиент и не автоматизируют игру. Используйте HUD
только в режимах, где это разрешено правилами площадки. Автоматические тесты
не заменяют проверку вашего клиента, Windows GUI и захвата на вашем ПК.
